
# 🐠 AquaControl

Magyar nyelvű akvarisztikai napló.

## Funkciók
- Két akvárium kezelése
- NO3, PO4, NH4, NO2 mérések
- pH, KH, GH és hőmérséklet rögzítése
- Mérési fotók csatolása
- Vízcsere naplózása
- Helyi adattárolás
- JSON biztonsági mentés és visszatöltés

## Használat
A GitHub Pages segítségével böngészőből használható.

## Fontos
Az adatok jelenleg az adott telefon böngészőjében tárolódnak.
A fotók csatolhatók, de a mérési értékeket kézzel kell beírni.
